# External motion library

Quaternius / KinemIQ CC0 motion archive v1.0, pinned by SHA-256 in tools/characters/stage_cc0_motion.py. Generated from the verified archive by prototype/tests/cc0_retarget_review.gd; 35 motions plus shared reference. No upstream meshes or root translation included.

The runtime uses only bounded relative Spine and Head rotations from Idle_relaxed and Idle_talking on the authored hero family. The anatomical locomotion solver remains responsible for foot contact, body position and combat poses. All other imported clips remain review assets until separate visual and gameplay acceptance. The workflow materializes the library only after the actual four-LOD gesture and natural-motion regression checks pass. Retarget review is not full visual approval.
