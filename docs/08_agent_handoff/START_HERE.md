## Wichtig bei einer neuen Sitzung

Vorhandenen Repository-Stand lesen. Diese Datei ist ein datierter Arbeitsstand, kein Ersatz für neuere Nutzeranweisungen. Eine Aufgabe, die inzwischen erledigt wurde, wird nicht erneut erzeugt. Eine neue ausdrückliche Freigabe zur Entwicklung erweitert den Auftrag nur in ihrem genannten Umfang. Es ist nicht nötig, für normale bereits autorisierte Planungsschritte eine weitere Zustimmung einzuholen.

Die ursprüngliche ZIP wird bei Bedarf als Quelle bereitgestellt. Fehlt sie, den fehlenden Quellenzugang benennen; die vorhandene neue Dokumentation kann trotzdem gelesen und weiterbearbeitet werden. Ein nicht vorhandener Engine-Zugang darf nicht durch erfundene Builds verdeckt werden.
