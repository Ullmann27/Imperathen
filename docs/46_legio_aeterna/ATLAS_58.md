# Politische Geografie im Startjahr

Der Atlas liest das Datum der Kampagne. Für 58 v. Chr. erläutert ein Klick auf eine der folgenden Regionen deren damalige politische Verhältnisse. Die simulierten Gruppen am Rhein führen weiterhin getrennte Bestände, Beziehungen und Chroniken im bestehenden Stammesmodell. Ortsmarken wie Utica repräsentieren die Umgebung. Die historische Reichweite einer Region begründet keinen Anspruch des Spielers auf deren Truppen.
