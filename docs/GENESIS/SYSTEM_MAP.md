# GENESIS-Systemkarte — AP01 Architecture Foundation bis AP36 Automation

**Quellbasis:** GENESIS fc28428; PRIMA 0f67268 liegt in seiner Vorgängerlinie. Die Karte ordnet echte GENESIS-Arbeitspakete ihrer belegten Implementierung zu. Quellpfad- und Testdateipräsenz ist kein Nachweis erfolgreicher Abnahme.

**Titel:** AP01–AP36 folgen der vom Auftraggeber vorgegebenen Liste. Frühere thematische Zeilen waren falsch zugeordnet und sind ersetzt. Die Einträge benennen vorhandene Codepfade, Tests, Grenzen und nächste Prüfschritte, nicht die Anzahl von Absätzen einer Anweisungsdatei. „Lücke“ heißt: Im abgegrenzten Runtime-Baum wurde kein dedizierter Implementierungspfad oder Prüftest gefunden. „Teilweise“ belegt nur die jeweils benannten Teilflächen.

**Zuständigkeit:** Mangels gefundenem CODEOWNERS, OWNERS oder MAINTAINERS sind nur Module/Dateipfade als Codeeigner angegeben; menschliche Zuständige sind nicht belegt.

Für einzelne Headless-Godot-Tests gilt das im Workflow verwendete Muster:

    "$GODOT_BIN" --headless --path prototype --audio-driver Dummy --fixed-fps 60 --script "res://tests/<test>.gd"

GODOT_BIN muss Godot 4.7.2 bezeichnen. Für den kombinierten PRIMA-Lauf gilt GODOT_BIN=/pfad/zu/godot tools/ci/operation_prima.sh. Einzelne Tests können zusätzliche Workflow-Flags und isolierte Datenverzeichnisse benötigen.

Auf fc28428 zählt ARCHITEKTUR_INDEX.md 273 Runtime-Skripte; im Runtime-Baum liegen ebenfalls 273 .gd-Dateien ohne Tests. Der Index ist ein deklarativer Inventarcheck, keine Vollständigkeits-, Integrations- oder Engineabnahme.

## Kernpfad

    project.godot -> main.tscn -> RuntimeDisplay
    Eingabe -> PlayerActionWorld / WorldModel.execute -> WorldState
    Storyinhalte -> WorldModel / Storymodule -> MissionEventBatch für lokale Story-Belege
    Weltzeit -> WorldClock / WorldCalendar -> Domänenfortschritt
    Spielstand -> WorldModel.save_game / load_game
    CI -> operation_prima.sh -> Import, Architekturchecks, gezielte Regressionen

MissionEventBatch.stage()/commit() ist eine vorhandene lokale Story-Feld-/Belegschnittstelle, kein allgemeines Transaktionssystem und kein Speicher. Die vollständige Integration von Storyaktionen in den autoritativen WorldModel-Befehlspfad bleibt ein gesonderter Abnahmepunkt.

## Statusauslegung

„Vorhanden“ bedeutet konkrete Codepfade plus begrenzte Tests, nicht vollständige AP-Abnahme. „Teilweise“ bedeutet, dass der Eintrag die vorhandenen Module eingrenzt, aber zentrale Verträge oder Integrationen offen lässt. „Lücke“ bedeutet kein dediziertes Runtime-/Testmodul im geprüften Quellbaum. Verwandte Systeme werden ausdrücklich nur als Nachbarpfade aufgeführt und nicht als Ersatzimplementierung ausgegeben. Siehe [Bekannte Grenzen](KNOWN_LIMITATIONS.md).
