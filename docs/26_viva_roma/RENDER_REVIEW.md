# 3D rendering and export evidence
The new workflow runs real Blender on the Ubuntu runner. It renders an architectural street fragment in legacy and VIVA modes with the same actual mesh coordinates, UV, camera, light, resolution, samples, denoising and exposure. It records geometry and image SHA-256. Different images alone do not establish better quality: a human visual comparison is required.
Then the city generator exports the full 240-house, 63-stall fictional city as GLB, plus its collision GLB; the verifier demands base colour, normal and metallic-roughness textures in at least ten exported materials. The exact generation result is stored as a workflow artifact. The runtime file name is roman_city_test.glb; the generator's name is imperathen_roman_test_city.glb. The integrator must stage the validated asset at prototype/assets/world/roman_city_test.glb and the associated collision file, then perform a full Godot import and walkthrough. Neither file is staged by this review branch.
