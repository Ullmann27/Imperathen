# Imperathen
IMPERATHEN – Historisches Open-World-Strategiespiel mit Echtzeit-Städtebau, dynamischer KI-Geschichte, Diplomatie, Rollenspiel und gewaltigen Schlachten.

## Aktueller Stand

Der Standardbranch `main` enthält derzeit die Projektbeschreibung und Dokumentation,
aber noch keinen Spielquellcode, keine Projektdateien und keine Build- oder
Testskripte. Die Beschreibung oben ist das Projektziel, keine Liste bereits
spielbarer Funktionen. Ein lokaler Spielstart, Build oder Testlauf ist aus diesem
Branch noch nicht möglich.

## Einstieg

Voraussetzung ist [Git](https://git-scm.com/downloads) mit HTTPS-Unterstützung und
eine Internetverbindung zu GitHub. Die folgenden Befehle in einem Terminal
ausführen (unter Windows zum Beispiel in Git Bash):

```sh
git --version
git clone --branch main --single-branch https://github.com/Ullmann27/Imperathen.git
cd Imperathen
git ls-files
```

Damit ist die derzeit verfügbare Dokumentation lokal vorhanden; es wurde noch
kein Spiel installiert oder gebaut. Eine Engine, Laufzeit oder zusätzliche
Abhängigkeiten lassen sich aus `main` noch nicht ableiten und müssen für diesen
Dokumentationsstand nicht installiert werden.
